# 1GNI — сайт-визитка

Учебный многостраничный статический сайт музыкального проекта 1GNI. Проект подготовлен под лабораторную работу № 0: HTML, CSS и Bootstrap 5.

## Страницы

- `site/index.html` — главная;
- `site/about.html` — об артисте;
- `site/discography.html` — дискография;
- `site/music.html` — музыкальные площадки;
- `site/gallery.html` — галерея и Bootstrap Carousel;
- `site/contacts.html` — контакты и демонстрационная Bootstrap Form.
