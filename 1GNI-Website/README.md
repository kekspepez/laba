# 1GNI — сайт-визитка

Учебный многостраничный статический сайт музыкального проекта 1GNI. Проект подготовлен под лабораторную работу № 0: HTML, CSS и Bootstrap 5.

## Страницы

- `site/index.html` — главная;
- `site/about.html` — об артисте;
- `site/discography.html` — дискография;
- `site/music.html` — музыкальные площадки;
- `site/gallery.html` — галерея и Bootstrap Carousel;
- `site/contacts.html` — контакты и демонстрационная Bootstrap Form.

Регистрация, вход, личный кабинет, API и база данных удалены: для статической визитки они не нужны.

## Что показать преподавателю

- Bootstrap-сетка: `container`, `row`, `col-*` на всех страницах;
- компоненты Bootstrap: Navbar, Card, Badge, Accordion, Alert, Form, Modal, Carousel;
- изображения: 10 уникальных файлов в `site/images/`, у изображений в HTML есть `alt`;
- общая навигация и футер с copyright и автором на каждой странице.

Шапка и футер формируются файлом `site/js/site.js` и вставляются в блоки `#site-header` и `#site-footer` на каждой странице.

## Docker: 6 контейнеров

Статический сайт запускается в пяти одинаковых контейнерах Nginx (`site1`–`site5`). Шестой контейнер (`gateway`) — входной Nginx, который распределяет запросы между пятью копиями сайта. Это учебная демонстрация нескольких контейнеров и балансировки; сама лабораторная № 0 по методичке Docker не требует.

### Запуск в Windows PowerShell

1. Установи и запусти Docker Desktop.
2. Открой PowerShell в папке `1GNI-Website`.
3. Собери образы и запусти все шесть контейнеров:

   ```powershell
   docker compose up -d --build
   ```

4. Открой сайт: <http://localhost:8080>
5. Посмотри контейнеры:

   ```powershell
   docker compose ps
   ```

6. Посмотреть логи входного Nginx:

   ```powershell
   docker compose logs -f gateway
   ```

7. Остановить контейнеры:

   ```powershell
   docker compose down
   ```

## Важно

- Контактная форма демонстрационная: показывает уведомление в браузере и не отправляет данные на сервер.
- Музыка открывается на официальной странице 1GNI в Яндекс Музыке: https://music.yandex.ru/artist/26214941. Сайт не скачивает и не хранит аудиофайлы.
- Bootstrap подключается через CDN, поэтому для его стилей и интерактивных компонентов нужен интернет.
